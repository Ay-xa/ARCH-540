## 条目接口（给以后加条目的人看）

```
MECH.<key> = {
  name, tilt, panelW, tiltMode,   // 下拉与滑块文字
  cap,                            // 一段说明：运动、翻译规则、来源、近似
  uses:{groupMode, tiltMode, gapPanel},   // 这个机构用到哪些排布控件，不用的自动隐藏
  preset:{...},                   // 切到这个条目时套的滑块值（含三个随机开关）
  setup(c)  → {geo, a, texW, texH, projW, vert}    // 每次重建算一次；vert = null（整高面状）或 {fA, gapH, D}（上部面状 + 膝盖挑檐）
  place(u)  → [sp0, sp1]          // 在已转向墙面的组里放一个单元，返回它沿立面的投影区间
}
```

引擎侧对应的能力：每扇窗可带 `screen / screenDay`（面状透光）和 `oh / ohIn / ohGap / ohOpacity`（挑檐），见 `_shared/ENGINE.md`。

## 两条路

每个条目在 Massing_v01 里同时走两条路：几何面片进 Ladybug 直射日照的 context（真实遮挡，但把板当作不透光，穿孔不起作用）；翻译结果 `dev` 进共享引擎（过热 %、采光系数，穿孔起作用）。两条路的趋势应一致，不一致说明翻译规则有问题。

## 可调性审计（2026-10-03，Massing_v01 的 GH 实现）

用一段 12 m 的墙逐项改参数，看几何（G，Rhino / Ladybug 看到的）和翻译结果（T，引擎看到的 screen / view）哪个会变：

| 参数 | #0 中轴转动板 | #1 竖轴折板 | #2 横轴折板 | #3 伞式六角 |
|---|---|---|---|---|
| 单元宽 unitW | G T | G T | G T | G T |
| 折角 / 倾角 tilt | G T | G T | G T | G T |
| 离墙 standoff | G | G | G T（挑檐深度） | G |
| 板厚 thick | T（投影加厚） | T（投影加厚） | **无** | **无** |
| 表皮 / 孔径 / 穿孔率 / 打孔开关 | T | T | T | T |
| 每组几片 groupMode | 只有配合间隔才有效 | 同左 | 同左 | 同左 |
| 组间隔 gapGroup、片间隔 gapPanel | G T | G T | G T | G T |
| 固定边 fixed | G（倾角方向） | G（固定边） | **无**（顶边固定） | **无**（角点固定） |
| 覆盖层、按立面开关 / 折角 | G T | G T | G T | G T |

页面按这张表启用控件：横轴折板和伞式六角的「板厚」「固定边」灰掉并写明原因；排布和间隔四个条目都能调。板的几何本身没有厚度（网格面片），板厚只进翻译的投影。

## 已知的共同近似

- 伞式折板花瓣折起后的立体形状对斜射光的角度效果未算，只算正面投影的星形。
- 面状遮挡是正面投影，不随太阳角度变；挑檐按太阳高度角逐小时算；竖鳍挡侧向太阳的效果尚未实现（会低估东西向竖向元素）。
- 穿孔对漫射光的透过率 = 穿孔率 × 1 / (1 + 0.75 × 孔深 / 孔径)，孔深取表皮厚度。
- 状态参数当作固定值比较；随时间变化的调节规则未做（SHADING_RULES.md §4.4）。
- 平面光斑用第 2 层的投影段，向里按约 45° 扩散混合，是示意。
