## 2. 这次要做的五件事

### 2.1 修：庭院延伸到顶层时顶层墙面消失（已修，2026-10-03）

原因：楼板实体用 `Extrusion.AddInnerProfile` 加洞，外圈不从原点出发时（退台层的矩形从 (0,3) 起）洞被放错位置，`ToBrep` 得到无效实体（日志：2d curve is not inside surface domain），Rhino 只画出一部分。页面的数据其实是对的（段、面积都在），只是 Rhino 里看不见墙。

改法：楼板改为「平面面（外圈 + 洞）→ 沿法线拉一层高」（`slab_brep`），三层都得到有效的封闭实体，体积核对过（240 m² × 3 m = 720 m³）。

### 2.2 改：庭院内墙默认不装遮阳（已改，2026-10-03）

按立面分设表里「庭院内墙」默认不勾。旧 json 里没有这张表时也按不装处理。要装仍然可以勾。

### 2.3 新：多个凹口、多个庭院，各自独立，tab 排列

**数据**：`ops[]` 本来就是数组，每条带 `id / type / apply / 参数 / at`。只需放开数量。id 规则：`notch01, notch02, …`，`court01, court02, …`。手柄点同名。

**GH**：`floor_outline` 现在取「第一个作用于本层的凹口」+ 所有庭院；改为**所有**凹口。多个凹口的外圈：按边、按位置排序后逐个切；两个凹口不能重叠、不能挨在 1 m 内（挨了就忽略后一个并写警告，和庭院对凹口的保护一样）；不同边的凹口在同一个角相遇也按 1 m 保护。庭院之间同样保护。

**页面**：拓扑操作组改成两排 tab：

```
凹口  [#1] [#2] [+]        庭院  [#1] [+]
```

点 tab 切换当前编辑的那一条，控件还是现在那几个（边、作用在、位置、宽、深 / 中心、宽、深）；`[+]` 新增一条（默认值 = 当前这条，位置错开）；每条有「删除」。摘要行列出全部：`凹口 B 深 4 · 凹口 A 深 6 · 庭院 6×6`。

**解读与段名**：第二个凹口的段名用它的边名 + 序号（A2 边的凹口壁叫 A2_1 …）；段名规则要先定下来再写，不然热力图与解读的归属会乱。庭院内墙现在 `Y1–Y4`、第二个 `Y2_1–Y2_4`，沿用。

**手柄**：每条一个点，颜色按类型（凹口红、庭院蓝），名字 = id。看门组件改为检查所有手柄点。

### 2.4 新：加体块（Add Mass）

用户的话：逻辑和拓扑开中庭一样，但方向相反，让室内面积增加。

**定义**：一个贴在某条外边上的矩形体块，参数和凹口完全对称：`{id:'mass01', type:'mass', apply, edge, pos, width, depth}`，depth 为**向外**的距离。它就是 Topology 文档里的 Push / Pull 的局部版：凹口是从边往里切，加体块是从边往外长。

**周界**：外圈在这条边上多出一个凸起（和凹口相反方向的三段）。段名：凸起的三段叫 `A+1 / A+2 / A+3`（朝向分别是边的左、外、右），区分于凹口的壁。

**与其他操作的关系**：
- 和凹口在同一条边上：按位置排序后依次处理，重叠或挨在 1 m 内就忽略后一个并警告。
- 和退台：第 2 组的矩形先退再加体块；体块 depth 可以超过退台量（那就是局部不退台，顶层伸出一块）。
- 庭院落在体块里也允许（庭院离外墙 ≥ 1 m 的规则按新周界算——这一条要改 `court_rect`，现在它按矩形算，得改成按周界算最近距离；第一版可以先只按矩形算，体块区域不许放庭院，写警告）。

**面积**：`results.floors[].area` 自动增加；解读里多一句「加体块让本层面积从 x 到 y，新增立面 z m」。

**手柄**：和凹口一样一个点在体块外缘中心，往外拖 = 加深。

**Rhino 建模**：周界仍是一个闭合多边形，楼板实体方法不变。

### 2.5 顺带：楼层组从两组放开到三组（可选）

Topology 文档的例子是 裙房 / 中段 / 顶 三组。现在 `groups = {podium, setback{A,B,C,D}}` 只有两组。如果 tab 的做法顺手，楼层组也可以做成 tab：每组「起止层 + 四边退台」。这一条我建议放在 2.3、2.4 之后看情况。

## 4. 要用户定的

1. 加体块的 depth 上限：建议 ≤ 短边的一半，和凹口对称；或者不限。
2. 体块里能不能放庭院：第一版建议不许（简单、明确），以后再放开。
3. 多个凹口在同一条边时，位置冲突谁让谁：建议「后加的让先加的」。
4. 楼层组要不要也放开到三组（2.5）。
