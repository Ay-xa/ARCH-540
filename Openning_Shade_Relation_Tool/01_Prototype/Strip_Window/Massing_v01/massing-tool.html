建筑与环境
楼层组
从 F1 起按每组的层数依次分配，最后一组拿剩下的楼层。每组四条边各自从基底向内退（退台 / 移边），退 0 = 不退。点 + 加一组，删 删掉当前组。
拓扑操作
凹口 来自 Rhino
可以有多个凹口，点 + 新增、删 删掉当前这个；先加的优先，后加的和已有凹口挨在 1 m 以内会被忽略并写警告。Rhino 里「Handles」图层上的红点是每个凹口的中心，拖它等于改位置和深度；宽只在这里改。谁后动谁算数。最深切到对面墙前 1 m。
庭院 来自 Rhino
可以有多个庭院。天井四面墙朝内开窗，第一个段名 Y1–Y4，第二个 Y2_1–Y2_4。Rhino 里的蓝点是每个庭院的中心。庭院离外墙至少 1 m，和凹口、其他庭院不能挨在 1 m 以内（挨着时 Grasshopper 忽略它并写警告）。
遮阳装置（机构库）
勾 = 装；拖上面的默认折角时各面跟随，单独拖某一面只改那一面。

整栋过热（无板 → 有板）— 整栋采光（无板 → 有板）— 整栋过热（无凹口 → 有凹口，均无板）— 整栋采光（无凹口 → 有凹口，均无板）— 冬季净得热（无板 → 有板）—
过热 = 全年室内高于 25 °C 的小时占比，被动房判据 ≤ 10%，建议 ≤ 5%；采光 = 房间带平均采光系数，3% 记为充足（Version_06 口径）。每段按「段长 × 进深 × 层数」的房间带独立算，整栋按房间面积加权。无凹口 = 同一矩形不开凹口，由页面直接算。这两列是引擎估算，已含「受晒」折减。
受晒 = 体量自遮挡后这段墙还能晒到的直射小时占同朝向自由墙面的比例（Ladybug：只有楼板遮挡 ÷ 没有遮挡），引擎用它折减直射得热，散射和采光不折；按分析期平均，套到全年。100 % = 没被自己的体量挡。
日照 = Ladybug「Direct Sun Hours」：分析期内窗条每点被太阳直射的小时数，三层平均，楼板（含凹口两侧）和遮阳装置作遮挡，不含周边建筑，也不含云（几何日照，不是辐射量）；入射辐射要装 Radiance 以后才能接。
