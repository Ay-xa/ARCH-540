三维视图：左键拖动旋转，右键拖动平移，滚轮缩放。单独编辑：双击一个体块：它变得更实，其他体块和功能变淡（仍可看到周边关系，但不能点选，不会挡住选面）；双击空白处或按 Esc 退出。白模：右上角按钮切换，只看体块。推拉：点击体块的一个面选中它（变橙色），拖橙色箭头沿这个面的法线推拉；立面吸附 1 m，顶面和底面吸附 0.1 m。拖动时只更新体块和数字，松开后再重新识别空间、排布功能（用户决定）。点空白处取消选面。蓝色箭头指北；橙色框是平面所看的标高。

三带只是评判背景，不是容器；默认 35 / 30 / 35（假设）
protected（冬季最低） buffered（冬季最低） tempered（冬季最低） controlled（冬季最低） 南带（直射阳光） 中间带（服务） 北带（漫射） 空白 = 走廊与未分配空间 体块轮廓 / 灰斜线 = 净高不足 挑空（这一层不设楼板） 需要调整（原位置） 建议位置 邻接满足 / 红虚线 不满足

平面显示所选标高的截面：只画在这个标高处存在的体块（底标高 ≤ 标高 < 顶标高）。粗黑线 = 外墙；红色虚线 = 体块贴着但接触宽度不足 5 m，不连通；灰色斜线 = 净高不足 3.0 m，不算可用楼面；细虚线 = 各个体块的轮廓。平面里不能改体块。拖动功能区可以挪动它（吸附 1 m，只在这一层里移动；拖动时绿色 = 落在可用楼面里，红色 = 不在）；拖过的功能区自动锁定（🔒），被它压住的没锁定的功能区会重新找位置。点选房间看说明，点体块选中体块。场地范围 90 × 52 m。
